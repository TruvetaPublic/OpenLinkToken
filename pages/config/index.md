# Configuration

Use the configuration guides as the canonical entry points for setting up
Open Link Token. The detailed pages are split by purpose so input, secret, and
runtime options do not get mixed with tuning details.

| Guide                                                      | Use it for                                                                                            |
| ---------------------------------------------------------- | ----------------------------------------------------------------------------------------------------- |
| [Configuration Guide](configuration.md)                    | CLI arguments, environment variables, input/output formats, processing modes, and secret requirements |
| [Configuration & Tuning](../configuration-tuning/index.md) | Column aliases, validation behavior, output details, ML1, and mode-specific tuning                    |

## Choose a starting point

- **Running a command**: Start with the [CLI Reference](../reference/cli.md) for
  the complete flag list, then use the [Configuration
  Guide](configuration.md) for environment and secret setup.
- **Preparing input data**: Use [Configuration & Tuning](../configuration-tuning/index.md)
  for accepted columns, aliases, and validation behavior.
- **Processing tokens in production**: Review [Security](../security.md) and
  [Running Open Link Token](../running-openlinktoken/index.md) alongside the
  configuration guides.
